# Epico outages email scheduler

Цей публічний технічний репозиторій містить тільки GitHub Actions workflow.

- Secret `OUTAGES_WORKER_TOKEN` містить production worker token.
- Variable `OUTAGES_SCHEDULER_ENABLED` дорівнює `true` лише після успішного ручного запуску.
- Workflow не містить коду сайту, адресатів або секретів.
